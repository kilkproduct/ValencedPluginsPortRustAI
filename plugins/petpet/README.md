PetPet anyone with /petpet

## What the original did

Sends a petpet GIF generated by api.popcat.xyz as a real uploaded attachment via FileModule and REST.

## What this port does

`/petpet` resolves the target's avatar and posts the generated image URL, which Discord unfurls. Same command, same service.

## Features

- /petpet <mention|id>, defaults to you
- Real avatar when the user has one, default avatar otherwise

## Settings

None.

## Phoenix API used

- `commands.register`
- `discord.get`
- `onSend-free`

## Known limitations

- Cannot upload the GIF as an attachment: Phoenix has no file-module or multipart API

## Privacy notes

- The target's avatar URL is sent to api.popcat.xyz.

## Install

Copy `dist/petpet.js` into Phoenix Unlock's plugin directory (Settings → Phoenix Unlocker → Plugins), or bundle
this folder with Phoenix Unlock's own tooling — the layout (`plugins/<name>/src/index.ts`, `// @` header
lines, esbuild IIFE) matches it exactly.
