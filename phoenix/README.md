# Phoenix-layout copies

Generated by `npm run build`. Each `<name>/src/index.ts` is the plugin's source, and
`<name>/<name>.js` is its built bundle.

To use these with Phoenix Unlock's own tooling:

```sh
cp -r phoenix/* /path/to/phoenix-unlock/plugins/
cd /path/to/phoenix-unlock && node web/tools/bundle-plugins.mjs
```
